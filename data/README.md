# Datos de parámetros

Este directorio contiene el archivo generado a partir del Excel oficial de ciclos.

## Archivo generado
- parameters.json: catálogo de ciclos y condiciones de pago usados por la calculadora.

## Re-generación
Ejecutar:

```bash
c:/Users/USER/Desktop/tem/.venv/Scripts/python.exe tools/convert_excel_to_parameters.py
```

## Nota
El archivo debe actualizarse manualmente cuando Gerencia entregue una nueva versión del Excel oficial.
